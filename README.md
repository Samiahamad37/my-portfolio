# Samia Hamad — Portfolio

Modern portfolio website for **Samia Adam Hamad**, built with Next.js, TypeScript, and Tailwind CSS.

**Repository:** [github.com/Samiahamad37/my-portfolio](https://github.com/Samiahamad37/my-portfolio)

This project replaces the previous static HTML portfolio with a single Next.js application that includes all projects, skills, and contact information in one place.

## Features

- Hero section with profile photo, stats, and core stack
- About section with education and conference history
- Skills organized by category
- Featured backend projects plus additional full-stack work
- Contact section with email and phone
- Electric purple & neon mint dark theme
- Fully responsive with mobile navigation
- SEO-friendly metadata and Open Graph tags

## Customize

Edit **`src/data/portfolio.ts`** to update personal info, skills, projects, and education.

Add your resume PDF to **`public/resume.pdf`** for the download link.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push to [my-portfolio](https://github.com/Samiahamad37/my-portfolio) on GitHub
2. Import the repo at [vercel.com](https://vercel.com)
3. Vercel auto-detects Next.js — click **Deploy**
